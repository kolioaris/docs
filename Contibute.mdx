Here is how you can get started contributing to kolioaris.xyz.

## Fork the repository

1. On GitHub, navigate to the [https://github.com/kolioaris/kolioaris.xyz](https://github.com/kolioaris/kolioaris.xyz) repository.
2. In the top-right corner of the page, click **Fork**. <img src="https://docs.github.com/assets/cb-34352/mw-1440/images/help/repository/fork-button.webp" alt="Fork Button" />
3. Under "Owner," select the dropdown menu and click an owner for the forked repository.
4. By default, forks are named the same as their upstream repositories. Optionally, in the "Repository name" field, type a different name to distinguish your fork.

## Make your changes

Edit the repository from your forked GitHub repository or by cloning the repository, editing it locally and pushing the changes to GitHub.

## Create a Pull Request

1. Navigate to [https://github.com/kolioaris/kolioaris.xyz](https://github.com/kolioaris/kolioaris.xyz).
2. Above the list of files, in the yellow banner, click **Compare & pull request** to create a pull request for the associated branch. <img src="https://docs.github.com/assets/cb-34097/mw-1440/images/help/pull_requests/pull-request-compare-pull-request.webp" alt="Pull Request - Compare Pull Request" />
3. On the page to create a new pull request, click **compare across forks**. <img src="https://docs.github.com/assets/cb-41260/mw-1440/images/help/pull_requests/compare-across-forks-link.webp" alt="Compare Across Forks Link" />
4. In the "base branch" dropdown menu, select the branch of the upstream repository where you want to merge changes. <img src="https://docs.github.com/assets/cb-96536/mw-1440/images/help/pull_requests/choose-base-fork-and-branch.webp" alt="Choose Base Fork and Branch" />
5. In the "head fork" dropdown menu, select your fork. Then, use the "compare branch" dropdown menu to select the branch where you made your changes. <img src="https://docs.github.com/assets/cb-96331/mw-1440/images/help/pull_requests/choose-head-fork-compare-branch.webp" alt="Choose Head Fork Compare Branch" />
6. Type a title and description for your pull request. Describe everything carefully and list all the changes you did.
7. To create a pull request that is ready for review, click **Create Pull Request**.
